# Project documentation

This folder contains the notes I used to define the analysis and explain the results. I separated these documents so a reviewer can follow the project from the business question to the data and then to the findings.

## What's here

- [`BRD.md`](BRD.md) — the business problem, objectives, scope, requirements, acceptance criteria and business rules.
- [`KPI_DICTIONARY.md`](KPI_DICTIONARY.md) — what each measure means, how it is counted and which denominator is used.
- [`DATA_SOURCE.md`](DATA_SOURCE.md) — the UCI source, dataset details, important fields, missing-value handling and reproducibility notes.
- [`FINDINGS_AND_LIMITATIONS.md`](FINDINGS_AND_LIMITATIONS.md) — the main patterns I noticed, follow-up questions I would ask, and the limits of the analysis.

The BRD in this folder is the revised version prepared for the portfolio. The original coursework brief is kept separately in [`evidence/`](../evidence/README.md).

These documents describe a historical, encounter-level analysis. They do not represent a hospital-approved requirements document or clinical recommendations.
