# Dashboard and analysis screenshots

These screenshots are supporting evidence for the coursework. The full set is available in the [14-page evidence report](../evidence/Patient_Readmission_Evidence_Report.pdf).

## Power BI dashboard

![Patient Readmission Analytics dashboard](https://github.com/user-attachments/assets/6ab2d441-ec97-4386-959b-6da4341d1cc0)

The dashboard compares recorded readmission labels across age bands, diagnosis counts, emergency visits and encounter measures. It is descriptive; it does not identify individual patients at validated high risk.

## SQL analysis

![SQL results for readmission count and proportion](https://github.com/user-attachments/assets/bf3d709f-bb50-411f-89d3-12a7285288e5)

The SQL evidence shows the count and share of encounter records in each readmission category. The `<30` category contains 11,357 of 101,766 encounters (11.16%).

## Excel summary

![Excel summary of readmission measures](https://github.com/user-attachments/assets/36a0a19c-6c3b-4452-be68-b7392b6c9c4b)

The summary distinguishes encounter count from distinct patient IDs. The original workbook also contains a tab labelled “AI Risk Level”; this portfolio does not claim a trained or clinically validated prediction model.
